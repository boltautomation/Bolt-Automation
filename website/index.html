What do I need to run Bolt?+

A Windows x64 computer, Chrome or Brave, and Ollama with a downloaded local model. The Windows package includes Node.js and the PDF-reading dependencies. The default model download is about 2.5 GB; the app guides one-time setup.

Do I need a paid AI API key?+

No. The desktop app uses a downloaded model through local Ollama. It doesn't need an OpenAI or Claude API key. Model speed and memory needs depend on your computer and the model you choose.

Will it always get the answer right?+

No. AI output and source checks can be wrong. Bolt uses two source-based passes and leaves unresolved questions for review when guessing is off. Check the original evidence before relying on an answer.

Can I automate any activity?+

Only activities you're authorized to automate. Follow your school or organization's policies and each connected site's terms. Bolt is for educational use, not cheating, fabricated participation, reward manipulation, harm, or unauthorized access.

Does the website collect my study files?+

This promotional website has no file uploads, sign-up forms, or analytics scripts. The desktop app stores its PDF library and saved answers on your computer. Vercel hosts this website, and download links take you to GitHub.
