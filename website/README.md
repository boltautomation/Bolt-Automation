# Bolt promo site

A buildless, responsive promotional site using Bolt's charcoal and yellow-green branding. Static HTML, CSS, and JavaScript; no analytics, forms, cookies, backend, or hosted AI calls.

Deploy this **website/** directory as the Vercel project root using the Other/static preset and no build command. Do not deploy the repository root, app runtime, or saved data. The desktop app itself remains a Windows download and does not run on this website.

Download links target the latest Windows release on GitHub. The interface visuals are clearly labeled illustrative previews. Feature tabs, a demo-only pace slider, mobile navigation, and FAQ disclosures work in the browser. Source checks and AI accuracy limits are explained, alongside the educational-use disclaimer.

Fonts are self-hosted; their Open Font License is in **assets/Manrope-OFL.txt**. The logo is the supplied Bolt asset. Preview locally with **node tools/preview-website.cjs** from the repository root.
